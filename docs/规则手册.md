# 百妖夜市 · 规则手册 v1.0

月圆之后，百妖开市。扮演妖怪商主，经营八街，竞拍铺契，以妖术争夺夜市魁首。2至6人；主要平衡基准4人，目标90至150分钟，尚待实桌验证。

## 组件与准备

48格棋盘、32张地产卡、24张奇缘签、24张夜巡签、48张百宝令（24种各两张）、6张商主卡、七种面额灵钱、六枚棋子、三枚六面骰、32枚建筑等级指示物、六色归属标记各32枚、停业标记18枚、缠身标记6枚、街区已用标记8枚、商主已用标记6枚、两枚全桌事件标记、轮数标记及六张流程提示。普通移动用两枚骰，借风远行用三枚。

每人12000灵钱：5000一张、2000两张、1000两张、500一张、200两张、100一张。纸币面额仅100、200、500、1000、2000、5000、10000；银行无限，可换钞或记账。无额外货物。每人随机一位商主、两张百宝令，无地产。棋子放开市门，开局不领奖。每人掷一骰，最高先手，并列重掷，之后顺时针。三类牌分洗，每库独立弃牌堆。

所有玩家各完成一个回合为一轮。2/3/4/5/6人分别玩24/21/18/16/14轮。每轮开始清除所有角色与街区的已用标记，移除上一轮全桌事件。角色不能交换；街区已用标记留在街区，转手不刷新。

## 回合流程

1. 状态恢复：移除以自己本回合开始为到期点的停业标记，包括已转手地产；处理金目狸掌收入。
2. 掷骰前：可打出一张符合时机的主动百宝令。
3. 掷骰移动：正常掷两骰；同点不加回合。掷骰后可按时机使用道具及角色／街区技能。
4. 落地结算：完成购买、竞拍、付租、抽牌和全部连锁效果。
5. 经营阶段：可普通升级一次、提出普通交易一次、主动回售资产，及使用本回合尚未使用的主动道具或可用街区能力。顺序自选。
6. 整理手牌：手牌上限四张，多余自选弃置。

每回合主动百宝令合计最多一张，被防御也消耗次数；防御牌不占主动次数。先确定步数再移动，不能看到落点抽牌后倒改。普通升级、交易和回售不能插入落地付款或竞拍。

## 地产、升级与街区

停在无主地产可原价买入，从妖铺开始；不买则公开竞拍。停在自己地产无事，停在对手营业地产付租。刚买入地产当回合可升级。每回合普通升级一次，无须站在目标地产；妖铺升华楼支付一次升级费；拥有同街至少两产时，华楼再付一次升级费升灵阁。灵阁为最高级。卡牌升级不占普通次数，但仍须满足条件。

租金等于当前等级基础租金加同街加成：持有1/2/3/4产分别加0/100/200/400。停业地产仍计持有数、终局价值和街区完整度，但不收租。集齐四产激活图鉴所列街区能力，失去完整街区立即失效，已建灵阁不降级。限每轮能力转手不刷新；重新集齐不刷新。

街区及角色的普通升级减费可以相加，最低0；不能用于卡牌升级。镜步技能可相加并与掷骰后道具组合；重掷必须先于所有步数修正。技能只适用于正常双骰移动（受乱线缠身时为单骰），不适用于替代移动、卡牌额外移动或三骰移动。借风远行在乱线缠身时失效，不能打出。

## 竞拍与普通交易

每回合最多一场竞拍。放弃无主地产时，若本回合尚无竞拍则发起；竞宝台可指定地图上的一处无主地产发起。已有竞拍则后续竞拍跳过，地产仍空置。起拍为印刷购买价的一半，每次至少加100，仅现金竞价。行动玩家先选择是否以起拍价出价，随后按座次；轮到时可提高当前价或退出，退出后本场不得回归。初始无人出价就空置。最高出价人之外的人都退出即成交；最高出价人在自己再次轮到前无人加价即成交。每次选择限5秒，超时视为退出；总时限60秒，期满最高有效出价成交。

所有人包括放弃原价购买者均可参加。出价不能超过现有现金，竞拍期间不能出售资产或打牌筹资。赤尾狐商的200补贴在成交时由银行代付，出价资格按未补贴全额检查；只在本轮第一次竞拍获胜时触发。无主地产不带建筑，成交后成为妖铺。

经营阶段仅当前玩家可向一位对手提出一次交易，限现金与地产，可组合、可赠与；谈判最多60秒，拒绝或超时也耗尽次数。允许时限内改同一提案，不换对象。双方同时交割；双方支付额均不能超过交割前现金，不能用本笔待收金额抵扣自身支出。禁止手牌交易、赊账、未来分红、口头免租与角色交换。地产等级和停业标记保留。

## 出售与清产重整

主动回售只在经营阶段。每次可拆一层建筑，按印刷升级费一半领取；可连续拆，最终最低妖铺。只有妖铺可回售土地，领取印刷购买价一半，归还银行并清除归属与状态。竞拍价与折扣不改变标准价值。骨玉完整街区的回售加200，按该笔出售前是否完整判定；卖出第一处后通常即失效。

强制付款现金不足时暂停一切其他动作，先确定防御与欠款，再由付款者自行选择拆楼、售地直至足够或资产全空。不能临时交易。足够即支付并保留余额；若资产全空仍不足，将全部现金交给收款方，免除该笔余债，银行发2400重整金，不淘汰、不计负债。重整金不能追补旧债。

重整后，本次回合余下时间不得购买、竞拍、升级、交易、发动角色或街区能力或使用主动牌；可防御、正常完成强制效果。若在他人回合重整，只限制该他人回合的余下时间，不跳过自己下回合。重整不改变棋子位置及手牌。每笔强制付款分别结算，可能多次触发；自愿消费须先足额支付，不能靠重整。无资产无现金同样执行重整，不得故意少卖资产。

## 卡牌与响应边界

奇缘签和夜巡签立即公开结算，百宝令收进手牌。卡面未注明收付款对象时均指银行。涉足街区指持有该街至少一产。卡牌需满足目标、额外弃牌或费用条件才可主动打出；无合法目标的即时签不执行该部分，按明确的替代分支处理，其余部分照常。所有折扣最低0。

防御在目标、金额或随机结果明确后、效果落实前声明。每人针对同一张牌或同一笔租金最多接受一次防御；听潮龙客技能、蛛锦街能力也占这次机会，不得再叠防御牌。防御不能被反制，也不能免除主动消费、手牌上限弃牌或作为主动牌费用的弃牌。全桌卡牌从行动玩家起顺时针逐人结算；防御只保护自己。

打出的牌先放结算区，效果全部结束才进弃牌堆，不能在自身效果中抽回。多张抽取先抽完、完成保留选择，再处理手牌超限；不能临时打主动牌腾位置。查看、偷牌、交换均在整个效果后检查上限。牌库不足时保留现有顶牌，将弃牌洗混接在底部；仍不足就处理实际可用数量，不退款、不补偿。

狸影换宝需要打出时至少还有一张其他手牌，目标至少有一张牌；目标防御后若无剩余手牌，效果终止，你不交牌。成功偷得一张后，必须交出打出前已有的另一张手牌，不能原样返还刚偷的牌。妙手探囊若防御后无手牌也终止。

停业标记记录施放者，至其下回合开始移除，不因转手改变。已经停业的地产不能再次被选为停业目标。乱线缠身持续至目标下个回合结束，不叠加；已被缠身者不能再被该牌选中。目标下回合仍可用不掷骰的替代移动；纸鹤引路在缠身时只重掷一枚。

商路遇阻和花雨满城为全桌规则事件，金光护体不能取消；本轮结束自动清除，同名不叠加。商路遇阻先使基础租金加联营后的总额减半，再计算访客的一次防御。每次减半向上取整到100灵钱。鬼酿街收益要求实际从玩家收到正数租金，银行支付及卡牌模拟租金不触发。

所有普通向前移动经过开市门领取2000，停在其上也只领一次；卡牌明确直接移至地点不经过沿途，以卡面发放金额为准，不触发狸食或花雨的正常经过奖励。额外移动结算新落点并完成连锁，但整个回合仍共用一次竞拍和主动牌次数。

## 胜负与示例

完成规定轮数后，末位玩家完整结束回合，立即结算，不另补最后交易。总资产＝现金＋地产印刷原价＋当前建筑层数乘印刷升级费＋每条完整街区2000。妖铺0层，华楼1层，灵阁2层。折扣、竞拍价、停业不改账面价值；手牌不计分。总资产高者胜，同分现金多者胜，仍同分共同获胜。

例：狐香街第二产月下脂铺价格1200、升级600、基础租金200/400/800。持有该街三产且该铺为灵阁，租金800＋200＝1000。商路遇阻时先减为500；若再用月下借宿则付300。出售灵阁先拆两层共得600，再售土地得600，合计1200；原价总资产价值2400。

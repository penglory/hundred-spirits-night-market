# 百妖夜市 · 印制与复用说明

## 成品制作方式

所有地产卡、功能牌、商主卡、流程卡和灵钱都使用 imagegen 直接生成完整成品：画面、名称、数字、效果文字与边框在同一张原图中。不采用“先生成插画，再叠加文字”的制作方式。打印文件只把完整原图放在纸张上；卡面内部没有额外文字覆盖。

地图采用16块完整成品分区，每块的格名、编号与画面一同生成。十二块边缘分区各四格，合计48格；四块中心分区组成夜市景观。将16张原图拼成4×4地图，不补写任何格名和数字。图鉴与规则手册是独立文档，不是覆盖在卡面上的文字层。

## 卡牌

卡牌裁切尺寸63×88毫米。全套实体140张：32张地产、24张奇缘、24张夜巡、48张百宝、6张商主、6张流程提示。A4每页九张，依次为同一张纸的正面页、背面页；最后一张纸允许有空位。

选择“实际大小／100%”和“长边翻转”，不要选择“适合页面”。背面列序已经为长边翻转作镜像排列，但每张图片本身未镜像。先仅打印前两页测试，再批量打印。打印机自动双面的机械误差可能不同，建议先用普通纸对光检查，或分别单面印后背靠背粘合。

牌面已包含装饰边框。纸张上的裁切线位于卡面外，不是图像的一部分。原始PNG单独保存，便于交给印店；精确裁切尺寸由印制PDF提供。若印店要求3毫米出血，向外延展外边框即可，不能裁去原有文字。

## 地图

地图物理尺寸420×420毫米。提供整幅PDF，以及A4六页拼接PDF。拼接版上排三张、下排三张；相邻页横向重叠9毫米、纵向重叠12毫米。只裁掉纸白边，按重叠画面吻合后粘贴。

地图的路线按0到47顺时针连续编号；按编号移动，47后回到0。0、12、24、36对应开市门、巡夜司、歇脚亭、百宝阁，分别位于四个角部分区。每块分区内部的装饰性道路不是额外地格。

每块分区的实际原图为1254×1254像素，4×4拼图为5016×5016像素，在420毫米成品上约303像素／英寸。同时提供12000×12000像素整幅放大输出，不代表原生细节增加。所有实际尺寸以资产清单为准。

## 合集与其他材料

全套A4印制合集共164页，页码索引见《合集页码》。合集中的地图与辅助组件均已插入空白背页，可以长边双面打印；单独的地图拼接PDF与辅助组件PDF则应单面打印。请按纸张材料分段印制。另备三枚六面骰、裁切工具与粘贴材料。

## 校对与版本

结构化规则以 data/game.json 为原始内容来源。生成图内的文字必须结合原图核对；OCR可能误读书法标题，不能把识别失败直接当作卡面错字，也不能把仅通过数据检查宣称为图文完全一致。发现错误应重新生成对应整面，不能后期覆盖改字。

本版是可打印试玩版。实桌时长与经济平衡尚待验证，不把自动检查等同于实桌测试。
